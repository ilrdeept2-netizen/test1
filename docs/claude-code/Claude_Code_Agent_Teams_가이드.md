# Claude Code Agent Teams (에이전트 팀) 가이드

## 에이전트 팀이란?

Claude Code의 **실험적 기능**으로, 하나의 리드 에이전트가 여러 팀원 에이전트를 만들어서
**동시에 병렬로** 작업을 진행할 수 있는 기능입니다.

### 기존 방식 vs Agent Teams

```
[기존 방식 - 순차 실행]
Claude → 코드 리뷰 → 버그 수정 → 테스트 작성 → 완료

[Agent Teams - 병렬 실행]
리드(팀장) ──┬── 팀원A: 코드 리뷰    ──┐
             ├── 팀원B: 버그 수정    ──┤── 결과 종합 → 완료
             └── 팀원C: 테스트 작성  ──┘
```

---

## 활성화 방법

`~/.claude/settings.json` 파일에 아래 내용을 추가합니다:

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}
```

---

## 사용 방법

활성화 후 Claude Code에서 자연어로 팀을 요청하면 됩니다.

### 예시 1: 코드 리뷰

```
PR #142를 리뷰할 에이전트 팀을 만들어줘:
- 한 명은 보안 검토
- 한 명은 성능 영향 확인
- 한 명은 테스트 커버리지 검증
```

### 예시 2: 디버깅

```
앱이 메시지 하나 보내면 종료되는 버그가 있어.
5명의 팀원을 만들어서 각각 다른 가설을 조사하게 해줘.
서로 상대방의 이론을 반박하면서 토론하도록 해줘.
```

### 예시 3: 새 기능 설계

```
CLI 도구를 설계할 에이전트 팀을 만들어줘:
- UX 담당 1명
- 기술 아키텍처 담당 1명
- 비판적 검토 담당 1명
```

## 팀 조작하기

| 동작 | 방법 |
|---|---|
| 팀원 목록 보기 | 리드 터미널에 자동 표시 |
| 팀원에게 직접 말하기 | `Shift+Up/Down`으로 선택 후 입력 |
| 팀원 세션 보기 | `Enter`로 진입, `Escape`로 나가기 |
| 작업 목록 보기 | `Ctrl+T` |
| 위임 모드 전환 | `Shift+Tab` (리드가 코드 안 만지고 조율만 함) |

---

## 표시 모드

### In-process (기본)
- 하나의 터미널에서 모든 팀원이 실행됨
- `Shift+Up/Down`으로 팀원 전환
- 별도 설치 불필요

### Split panes (분할 화면)
- 각 팀원이 별도 패널에서 실행됨
- tmux 또는 iTerm2 필요

설정:
```json
{
  "teammateMode": "in-process"
}
```
또는 실행 시:
```bash
claude --teammate-mode in-process
```

## 서브에이전트 vs 에이전트 팀

| | 서브에이전트 | 에이전트 팀 |
|---|---|---|
| **컨텍스트** | 결과만 메인에 반환 | 완전히 독립적 |
| **소통** | 메인에만 보고 | 팀원끼리 직접 대화 가능 |
| **조율** | 메인이 모든 작업 관리 | 공유 작업 목록으로 자율 조율 |
| **적합한 작업** | 결과만 중요한 집중 작업 | 토론/협업이 필요한 복잡한 작업 |
| **토큰 비용** | 낮음 | 높음 (팀원마다 별도 컨텍스트) |

---

## 주의사항

- **실험적 기능**: 세션 복구, 작업 조율, 종료 등에 제한이 있음
- **토큰 사용량 높음**: 팀원마다 별도 컨텍스트 윈도우 사용
- **파일 충돌 주의**: 같은 파일을 여러 팀원이 수정하면 덮어쓰기 위험
- **중첩 팀 불가**: 팀원이 자체 팀을 만들 수 없음
- **세션당 1팀**: 새 팀을 시작하려면 기존 팀을 정리해야 함

---

## 팁

1. **처음에는 리서치/리뷰부터**: 코드 작성보다 조사/리뷰 작업으로 시작하면 안전
2. **팀원에게 충분한 컨텍스트 제공**: 스폰 프롬프트에 구체적 지시 포함
3. **적절한 작업 크기**: 너무 작으면 오버헤드, 너무 크면 조율 어려움
4. **팀원당 5-6개 작업**: 생산성 유지에 적절한 수준
5. **정리는 반드시 리드가**: `팀 정리해줘`로 리소스 정리
