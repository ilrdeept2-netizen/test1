# Claude 모바일 앱 업무 도구 연동 가이드

> 작성일: 2026-03-25
> 기준: Claude 모바일 앱 정식 업무 도구(Tool Use) 연동 기능 출시

---

## 개요

Claude 모바일 앱에 업무용 도구 연동(Tool Integration) 기능이 정식 추가되었습니다.
이제 PC 없이 스마트폰에서 직접 외부 서비스와 연동하여 실무 작업을 처리할 수 있습니다.

---

## 지원 도구 목록

| 카테고리 | 도구 | 주요 기능 |
|----------|------|-----------|
| 디자인 | **Figma** | 디자인 파일 확인, 코멘트 작성, 프레임 미리보기 |
| 프레젠테이션 | **Canva** | 슬라이드 생성, 템플릿 기반 편집, 이미지 삽입 |
| 데이터 분석 | **Amplitude** | 대시보드 조회, 이벤트 데이터 분석, 차트 확인 |
| 프로젝트 관리 | **Notion** | 페이지 생성/편집, 데이터베이스 조회 |
| 커뮤니케이션 | **Slack** | 메시지 전송, 채널 요약, 스레드 검색 |
| 코드 | **GitHub** | PR 확인, 이슈 관리, 코드 리뷰 |

> 지원 도구는 계속 확대되고 있으며, 위 목록은 주요 도구 기준입니다.

## 모바일 연동의 핵심 활용 시나리오

### 1. 이동 중 디자인 리뷰 (Figma)

- 디자이너가 공유한 Figma 링크를 Claude에 전달
- 모바일에서 바로 디자인 프레임 확인 및 피드백 작성
- 디자인 시스템 컴포넌트 명세 조회

### 2. 빠른 프레젠테이션 제작 (Canva)

- "이번 주 KPI 요약 슬라이드 만들어줘"와 같은 자연어 요청
- Claude가 Canva API를 통해 슬라이드 자동 생성
- 생성된 슬라이드를 모바일에서 바로 미리보기 및 공유

### 3. 데이터 대시보드 모니터링 (Amplitude)

- 주요 지표(DAU, 리텐션, 전환율 등) 모바일 조회
- "지난 7일간 신규 가입자 추이 보여줘" 등 자연어 질의
- 이상 징후 발견 시 즉시 팀에 공유 가능

### 4. AI 에이전트 작업물 모바일 검토

- 외부 서버에서 실행 중인 Claude 에이전트의 작업 결과를 모바일로 수신
- 코드 변경 사항, PR, 분석 리포트 등을 이동 중 검토 및 승인
- 에이전트에게 추가 지시 또는 수정 요청

## 설정 방법

### 도구 연결

1. Claude 모바일 앱 실행
2. **설정** → **연동 도구(Integrations)** 진입
3. 원하는 도구 선택 후 OAuth 인증 진행
4. 연결 완료 후 대화에서 바로 사용 가능

### 권한 관리

- 각 도구별 읽기/쓰기 권한을 개별 설정 가능
- 민감한 작업(삭제, 공개 배포 등)은 별도 확인 절차 적용
- 연동 해제는 설정에서 언제든 가능

## PC 연동과의 차이점

| 항목 | PC (데스크톱/웹) | 모바일 |
|------|-------------------|--------|
| 도구 연동 | 전체 지원 | 정식 지원 (동일) |
| 파일 업로드 | 드래그 앤 드롭 | 카메라/갤러리 선택 |
| 멀티태스킹 | 브라우저 탭 병행 | 앱 전환 또는 분할 화면 |
| 에이전트 모니터링 | 실시간 터미널 확인 | 푸시 알림 기반 검토 |
| 사용 맥락 | 집중 작업 | 이동 중 빠른 확인/승인 |

## 실무 워크플로우 예시

```
[오전 출근길 - 모바일]
  ├── Amplitude 대시보드로 전일 지표 확인
  ├── Figma에서 디자이너 업데이트 리뷰
  └── Slack으로 팀 회의 안건 요약 전달

[오후 사무실 - PC]
  ├── Claude Code로 코드 작성 및 PR 생성
  ├── Canva로 발표 자료 상세 편집
  └── Amplitude 심층 분석 리포트 작성

[퇴근 후 - 모바일]
  ├── AI 에이전트 작업물(CI/CD 결과, 코드리뷰) 확인
  ├── 긴급 이슈 발생 시 모바일에서 바로 대응
  └── 다음날 작업 지시 예약
```

## 주요 변화: AI를 대하는 방식의 전환

모바일 도구 연동이 가져온 가장 중요한 변화는 **AI 활용 패러다임의 전환**입니다.

- **Before**: AI는 PC 앞에서 사용하는 도구
- **After**: AI는 손안에서 항상 접근 가능한 실무 파트너

해외에서는 이미 다음과 같은 활용 사례가 보고되고 있습니다:
- 이동 중 외부 서버의 AI 에이전트 작업물을 모바일로 검토/승인
- 현장(공장, 매장 등)에서 실시간 데이터 분석 결과 확인
- 비개발자가 자연어로 대시보드 생성 및 보고서 작성

AI가 **손안의 실무 도구**로 자리잡는 속도가 빠르게 가속되고 있으며,
이 흐름에 맞춰 모바일 기반 워크플로우를 미리 구축해 두는 것이 중요합니다.
