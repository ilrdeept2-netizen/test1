# Google AI Pro (Antigravity) 할당량 잠금 문제 분석

> 2026년 3월 12일 기준 조사 결과

## 문제 요약

Google AI Pro (Antigravity IDE) 유료 구독자들이 광고된 5시간 할당량 갱신 대신 **수일간 모델 접근이 차단**되는 문제를 광범위하게 보고하고 있습니다.

### 보고된 증상

| 항목 | 광고된 정책 | 실제 경험 |
|------|-----------|----------|
| 할당량 갱신 주기 | 5시간마다 | 3~7일 |
| Gemini Pro | 5시간 후 리셋 | 5일 이상 잠금 |
| Sonnet 4.6 (Claude) | 5시간 후 리셋 | 6~7일 잠금 |
| 전날 밤 잔여 할당량 | 유지 | 다음날 갑자기 소진/잠금 |

## 근본 원인 분석

### Gemini 3.1 업데이트와의 연관성

2026년 2월 19~20일경 Gemini 3.1이 Antigravity IDE에 배포된 시점부터 문제가 시작되었습니다:

- **Gemini 3.1 Pro (High)** 및 **Gemini 3.1 Pro (Low)** 모델 모두 "5일 0시간 후 갱신"이라는 메시지를 표시
- 이는 광고된 5시간 갱신 주기와 직접적으로 모순됨
- 일부 사용자는 모델을 사용하지도 않았는데 7일간 할당량이 제한됨

### 영향을 받는 모델

1. **Gemini 3.1 Pro (High/Low)**: 5일 이상 잠금
2. **Claude Sonnet 4.6** (Antigravity 경유): 6일 이상 잠금
3. **Claude Opus** (Antigravity 경유): 6일 잠금 보고

## Google AI Developers Forum 주요 버그 리포트

다수의 Pro 사용자들이 동일한 문제를 보고하고 있습니다:

1. **5일 잠금 버그** — Gemini 3.1 업데이트 이후, 낮은 사용량에도 불구하고 5일간 잠금
2. **5시간 갱신 미이행** — 광고된 대로 할당량이 5시간마다 리셋되지 않음
3. **4일 잠금** — Antigravity IDE에서 Gemini 3.1 Pro 할당량 4일 잠금
4. **3일 긴급 잠금** — Gemini 3.1 마이그레이션 버그로 인한 3일 잠금
5. **7일 무기한 연장** — Pro 사용자의 Gemini 3.1 Pro 및 Claude 할당량이 7일로 무기한 연장

## 기술적 세부사항

### API 수준 할당량 리셋
- **RPD (일일 요청 수)** 할당량은 태평양 시간 자정에 리셋
- 한국 시간(KST) 기준: 오후 4시~5시경
- 무료 사용자: 일 20~100건 / Tier 1 유료 사용자: 일 250건

### 할당량 계산의 불투명성
- Google은 정확한 할당량 소진 메커니즘을 공개하지 않음
- "토큰 기반" vs "요청 기반" 계산 방식이 혼재
- 긴 컨텍스트 요청이 할당량을 불균형적으로 소진할 가능성

## 권장 대응 방안

### 즉시 조치 가능

1. **Google AI Developers Forum에 버그 리포트 제출**
   - 구체적인 잠금 시간, 사용 패턴, 스크린샷 포함
   - 기존 스레드에 댓글 추가하여 문제의 심각성 강조

2. **Google 지원팀에 환불 요청**
   - 광고된 서비스(5시간 갱신)와 실제 서비스(수일 잠금)의 불일치
   - 소비자 보호법에 따른 정당한 환불 사유

3. **대안 서비스 고려**
   - Anthropic claude.ai Pro 직접 구독 (월 $20)
   - OpenAI ChatGPT Pro
   - API 키를 통한 직접 사용 (사용량 기반 과금, 잠금 없음)

### 장기적 대안

1. **API 직접 사용**: Google AI Studio 또는 Anthropic API를 직접 사용하면 "잠금"이 아닌 사용량 기반 과금
2. **다중 제공자 전략**: 하나의 서비스에 의존하지 않고 여러 AI 제공자를 병행 사용
3. **로컬 모델 병행**: Ollama 등을 통한 로컬 LLM 사용으로 기본 작업 처리

## 결론

이 문제는 **Gemini 3.1 마이그레이션과 관련된 광범위한 버그**로 확인됩니다. 귀하만의 문제가 아니며, Google AI Developers Forum에 다수의 동일 보고가 존재합니다. Google이 이 문제를 인지하고 있지만, 아직 명확한 해결 일정은 발표되지 않았습니다.

유료 서비스에서 광고된 기능(5시간 갱신)이 제공되지 않는 것은 소비자 권리 침해에 해당할 수 있으며, 환불을 요청하거나 대안 서비스로 전환하는 것을 권장합니다.
