# Antigravity 사용량 & 모델 가이드

> 작성일: 2026-03-01 | Antigravity에서 자동 생성

---

## 1. Gemini Ultra 구독과 Antigravity의 관계

### 💰 요금 구조
Antigravity는 **Google AI 구독 플랜에 통합**되어 있습니다.

| 구분 | 가격 | Antigravity 사용 |
|------|------|-----------------|
| **무료** | $0 | 가능하지만 rate limit 매우 낮음 |
| **Google AI Pro** | ~$20/월 | 중간 수준의 한도 |
| **Google AI Ultra** (현재 구독 중) | ~$42/월 (3개월 $124.99) | **최대 한도 제공** ✅ |

> **핵심:** Antigravity는 별도 결제가 아닙니다. Google AI Ultra(= Gemini Ultra) 구독에 포함되어 있어, 추가 비용 없이 사용 가능합니다.

### 📊 Ultra 구독자의 Antigravity 한도
- **120 요청/분** (분당)
- **2,000 요청/일** (일일)
- **1,000,000 토큰** 컨텍스트 윈도우 (로컬 코드베이스 인식)

## 2. 사용 가능한 모델과 특성

Antigravity에서는 대화 시작 시 **모델을 선택**할 수 있습니다.

### 🤖 모델 목록

| 모델 | 제공사 | 강점 | 약점 |
|------|--------|------|------|
| **Gemini 3.1 Pro (High)** | Google | 대용량 컨텍스트(100만 토큰), 계획 수립, 리서치 | 복잡한 코드 수정 시 간혹 불안정 |
| **Gemini 3.1 Pro (Low)** | Google | 빠른 응답, 가벼운 작업에 적합 | 추론 깊이 낮음 |
| **Gemini 3 Flash** | Google | 매우 빠른 속도 | 복잡한 작업엔 부족 |
| **Claude Sonnet 4.6** | Anthropic | 균형 잡힌 성능, 빠른 속도 | - |
| **Claude Opus 4.6** | Anthropic | 최고 수준의 정밀 코딩, 깊은 추론 | 느림, 연산량 높음 |
| **GPT-OSS-120B** | 오픈소스 | 무료/오픈소스 기반 | 성능 불확실 |

### ⚠️ Claude 모델 사용 시 주의사항
Claude Opus/Sonnet는 Anthropic 모델이지만 Antigravity에서 사용 가능합니다.
**이 모델들도 Google AI Ultra 구독 한도 내에서 소진됩니다** (별도 Anthropic 결제 불필요).
단, Opus는 연산량이 높아서 같은 한도 내에서 더 빨리 소진될 수 있습니다.

## 3. Gemini Ultra 구독의 전체 일일 한도 (Antigravity 외)

**Antigravity 사용과 Gemini 앱 사용은 별도 한도입니다.**

### 🔋 Gemini 앱 (gemini.google.com) 일일 한도
| 기능 | 일일 한도 |
|------|----------|
| Thinking 모드 프롬프트 | **1,500회/일** |
| Pro 모드 프롬프트 | **500회/일** |
| Deep Think 3.1 | **10회/일** |
| Gemini Agent | **200회/일** (동시 3개) |
| Deep Research | **200건/일** |
| 이미지 생성 | **1,000장/일** |
| 음악 생성 | **100곡/일** |
| 동영상 생성 (Veo 3.1) | **5편/일** |

> **Antigravity에서 아무리 많이 써도 위의 Gemini 앱 한도에는 영향을 주지 않습니다.**
> 예: Deep Think를 하루 10번 쓸 수 있는 건, Antigravity 사용량과 무관합니다.

## 5. 결론: 클로드 대비 한도 비교

| 항목 | Claude Pro 구독 | Google AI Ultra + Antigravity |
|------|----------------|------------------------------|
| 가격 | $20/월 | ~$42/월 (Gemini 전체 포함) |
| 코딩 어시스턴트 한도 | 5시간 롤링 윈도우 (매우 빡빡) | **하루 2,000회** (넉넉) |
| 모델 선택 | Claude만 가능 | Gemini + Claude + GPT 모두 가능 |
| 기타 AI 기능 | 없음 | Deep Think, Deep Research, 이미지/영상 생성 등 포함 |

> 💡 클로드 구독에서 겪었던 사용량 한도 문제는 Antigravity에서는 거의 느끼지 못할 것입니다.

## 6. 사용량 추적 방법: 클로드 vs Gemini/Antigravity

### 📊 비교표

| 항목 | 클로드 | Gemini / Antigravity |
|------|--------|---------------------|
| **실시간 사용량 바** | ✅ 대화창에서 바로 보임 | ❌ 없음 |
| **한도 도달 경고** | ✅ "rate limit" 알림 | ⚠️ 한도에 가까워지면 알림 |
| **정확한 수치 확인** | ✅ 사용량 탭 | 간접적으로만 가능 |
| **대시보드** | ✅ 있음 | ❌ Antigravity 전용 대시보드 없음 |

### 🔍 현재 가능한 확인 방법

1. **Gemini 앱 자동 알림**: 한도에 가까워지면 Gemini 앱이 경고 (정확한 숫자는 안 보여줌)
2. **AI 크레딧 잔액 확인**: Google One 앱 또는 Whisk/Flow 앱에서 확인 가능 (매월 25,000 크레딧)
3. **Google AI Studio 대시보드**: API 호출 이력, 토큰 수, 빌링 정보 확인 가능
4. **Antigravity 자체**: 현재 사용량 대시보드 없음 → 한도 도달 시 오류 메시지 방식

### 💡 현실적 대응

Ultra 구독자(하루 2,000회)는 일반적인 업무로 한도를 채우기 매우 어려움.
**신경 쓸 것**: Deep Think 3.1 (하루 10회)만 아껴 사용하면 됨.

> ⚠️ Antigravity는 아직 퍼블릭 프리뷰 단계로, 사용량 대시보드 기능은 향후 추가될 가능성이 높음 (2026-03-01 기준)
