## 1. Show Widget이란?

**Show Widget**은 Anthropic이 2026년 3월 12일 공개한 Claude의 신규 기능으로, 대화 내에서 텍스트 응답 대신 또는 텍스트와 함께 **인라인 인터랙티브 시각 콘텐츠**를 직접 렌더링하는 기술이다.

### 핵심 개념

Claude가 텍스트로 설명하는 것보다 시각적으로 전달하는 것이 더 효과적이라고 판단할 때, 자동으로 차트·그래프·다이어그램·구조화 데이터 카드 등을 생성하여 대화 흐름 속에 인라인으로 표시한다.

### 출처

이 기능은 Anthropic이 이전에 선보인 **"Imagine with Claude"** 임시 체험 기능의 확장판이다. 당시 코드 작성 없이 실시간으로 인터랙티브 시각화를 생성하는 실험적 경험을 제공했으며, 이번 업데이트를 통해 일반 채팅 대화에 정식으로 통합되었다.

## 2. 핵심 기술 특성

| 특성 | 세부 내용 |
|------|-----------|
| **렌더링 기술** | HTML + SVG (이미지 생성 아님) |
| **표시 방식** | 인라인 (사이드 패널 X) |
| **수명** | 일시적 (대화가 진행되면서 변경되거나 사라짐) |
| **활성화 방식** | 기본값 ON (전체 사용자, 무료 포함) |
| **인터랙티브 입력** | 객관식 선택지 등 구조화 질문 제공 가능 |

### 기술 흐름

```
사용자 질문
    │
    ▼
[Claude 판단]
텍스트 설명보다 시각화가 효과적인가?
    │
    ├──→ YES → HTML/SVG 위젯 인라인 렌더링
    │           대화 흐름과 함께 동적 변경
    │
    └──→ NO  → 기존 텍스트 응답
```

## 3. 제공되는 위젯 유형

### 3.1 데이터 시각화

- **차트(Charts)**: 막대, 선, 원, 산점도 등 다양한 형태
- **그래프(Graphs)**: 트렌드 분석, 비교 그래프
- **다이어그램(Diagrams)**: 플로우차트, 관계도, 아키텍처 도식

### 3.2 실시간 데이터 위젯 (웹 검색 연동 시)

- **날씨(Weather)**: 현재 날씨 상태 및 예보 카드
  - 특정 위치를 물어보면 포맷된 날씨 카드로 표시
  - 현재 데스크톱 전용 (iOS 앱 미지원)

- **레시피(Recipe)**: 조리법 카드
  - 텍스트 블록보다 따라하기 쉬운 포맷으로 레시피 제공
  - 현재 데스크톱 전용

### 3.3 인터랙티브 입력

- **구조화 질문**: Claude가 사용자에게 객관식 선택지를 인터랙티브하게 제시
- 사용자가 텍스트를 직접 입력하는 대신 클릭으로 응답 가능

## 5. Cowork에서의 역할과 시너지

Show Widget은 단순 채팅 기능을 넘어, **Claude Cowork의 작업 효율성을 근본적으로 높이는 역할**을 한다.

### 5.1 작업 계획 시각화

Cowork가 복잡한 작업을 수행하기 전, 태스크 분해 계획을 **다이어그램으로 인라인 표시**할 수 있다.

```
예시:
사용자: "이 폴더의 데이터를 분석해서 보고서 만들어줘"
Claude: [태스크 분해 다이어그램 위젯 표시]
    ├── 에이전트 A: CSV 분석
    ├── 에이전트 B: 차트 생성
    └── 에이전트 C: 보고서 작성
→ 사용자가 계획을 시각적으로 확인 후 승인
```

### 5.2 진행 상황 모니터링

서브에이전트들이 작업을 수행하는 동안, **진행률 위젯**이 인라인으로 업데이트되어 어느 단계가 완료되었는지 실시간으로 파악할 수 있다.

### 5.3 데이터 분석 결과의 즉각적 시각화

Cowork가 CSV·Excel 데이터를 분석하면, 결과를 텍스트 설명 대신 **인라인 차트**로 즉시 보여준다. 사용자는 별도 파일을 열지 않고도 핵심 인사이트를 대화 창에서 바로 확인할 수 있다.

### 5.4 의사결정 지원: 인터랙티브 선택지

Cowork 작업 중 사용자의 결정이 필요한 시점에, Claude가 **객관식 위젯**으로 선택지를 제시한다.

```
예시:
Claude: "보고서 형식을 선택해 주세요"
    [A] 경영진 요약본 (1페이지)
    [B] 상세 분석 보고서 (전체)
    [C] 데이터 시각화 대시보드
→ 클릭 한 번으로 선택 완료
```

### 5.5 Excel·PowerPoint 연동과의 결합

2026년 3월 11일 발표된 **Claude in Excel/PowerPoint Skills**와 결합하면, Cowork가 스프레드시트 데이터를 분석하고 그 결과를 위젯으로 미리보기한 뒤 실제 파일에 반영하는 워크플로우가 가능해진다.

## 6. 사용 방법

### 자동 생성

Claude가 스스로 시각화가 필요하다고 판단하면 자동으로 위젯을 생성한다.

### 직접 요청

사용자가 명시적으로 시각화를 요청할 수 있다:

```
"이 데이터가 시간에 따라 어떻게 변하는지 시각화해줘"
"차트로 보여줘"
"이 내용을 다이어그램으로 그려줘"
```

### 위젯 조정

생성된 위젯에 대해 추가 수정이나 정보 요청 가능:

```
"색상을 파란색으로 바꿔줘"
"여기에 2025년 데이터도 추가해줘"
"이 부분을 더 자세히 설명해줘"
```

## 7. 지원 범위 및 제한사항

### 지원 플랜

| 플랜 | Show Widget 지원 |
|------|-----------------|
| Free | **지원** (기본 시각화) |
| Pro | **지원** (전체 기능) |
| Max | **지원** (전체 기능) |
| Team/Enterprise | **지원** (전체 기능) |

> 모든 사용자에게 기본값 ON으로 활성화

### 실시간 데이터 위젯 (날씨·레시피 등)

- 웹 검색 기능 활성화 필요
- 현재 **데스크톱 전용** (iOS 앱 미렌더링)
- Android 앱 지원 미정

### 현재 제한사항

1. 모바일(iOS) 앱에서 날씨·레시피 카드 미표시
2. 실시간 데이터 위젯은 웹 검색 연동 필수
3. 위젯은 일시적 — 영구 저장이 필요하면 Artifacts 사용 권장

## 8. 향후 전망

### 단기 (2026년 Q2)

- iOS·Android 앱에서 전체 위젯 유형 지원 예상
- Cowork와의 깊은 통합으로 작업 시각화 고도화
- 추가 실시간 데이터 소스 연동 (주가, 환율, 스포츠 스코어 등)

### 중기 (2026년 하반기)

- **교차 기기 동기화**: 동일 위젯을 여러 기기에서 일관되게 표시
- Enterprise 환경에서 조직 맞춤 데이터 위젯 구성 가능성
- Microsoft Copilot Cowork와의 위젯 공유 연동

### Cowork 진화 방향에서의 위치

Show Widget은 Cowork의 **투명성(Transparency)** 원칙을 UI 레벨에서 구현하는 핵심 요소다. Anthropic이 강조하는 "AI가 자신의 추론 과정을 실시간으로 공개"한다는 비전이, 텍스트를 넘어 시각적 언어로 확장되는 것이다.
