## 1. 개요

**Claude Cowork**는 Anthropic이 2026년 1월 12일에 발표한 데스크톱 AI 에이전트 기능이다. 기존의 대화형 AI 챗봇 패러다임에서 벗어나, **로컬 파일 시스템에 직접 접근하여 실질적인 작업을 수행**하는 자율형(Agentic) AI 어시스턴트이다.

기존 Claude가 "질문에 답하는" 모델이었다면, Cowork는 "일을 해주는" 동료(Co-worker)로 포지셔닝된다. 사용자가 특정 폴더에 대한 접근 권한을 부여하면, Claude가 해당 폴더 내 파일을 읽고, 수정하고, 생성할 수 있다.

### 핵심 차별점

| 항목 | 기존 Claude 채팅 | Claude Cowork |
|------|-------------------|---------------|
| 상호작용 방식 | 일문일답 대화 | 자율적 태스크 수행 |
| 파일 접근 | 수동 업로드/다운로드 | 로컬 파일 직접 접근 |
| 작업 범위 | 단일 응답 생성 | 다단계 작업 자동화 |
| 병렬 처리 | 불가 | 서브에이전트를 통한 병렬 실행 |
| 출력물 | 텍스트 응답 | 실제 파일(Excel, PPT, 문서 등) |

## 2. 탄생 배경

### Claude Code에서 Cowork까지

2024년 말, Anthropic은 소프트웨어 엔지니어를 위한 터미널 기반 도구인 **Claude Code**를 출시했다. 원래 반복적인 프로그래밍 작업을 자동화하기 위한 도구였지만, Anthropic은 흥미로운 현상을 발견했다:

> "개발자들이 코딩 도구를 코딩 이외의 거의 모든 작업에 사용하기 시작했다."

이 관찰이 Cowork 개발의 직접적인 계기가 되었다. Anthropic은 코딩 지식이 없는 일반 사용자도 동일한 에이전트 경험을 누릴 수 있는 도구를 만들기로 결정했다.

### 개발 과정

Anthropic 내부 관계자에 따르면, Cowork는 **약 1주 반(10일 내외)** 만에 개발되었으며, 대부분의 개발 과정에서 **Claude Code 자체를 활용**하여 구축했다. 이는 AI가 AI 도구를 만드는 "자기 부트스트래핑(self-bootstrapping)" 사례로 주목받았다.

## 3. 핵심 기능

### 3.1 로컬 파일 직접 접근

- 지정된 폴더 내 파일을 직접 읽기/쓰기/생성
- 수동 업로드/다운로드 없이 즉시 작업 가능
- 파일 삭제 시에는 반드시 사용자의 명시적 허가를 요구

### 3.2 서브에이전트 병렬 처리

- 복잡한 작업을 여러 개의 하위 태스크로 자동 분해
- 독립적인 서브에이전트를 동시에 생성하여 병렬 실행
- 결과를 집계하여 최종 산출물 생성

### 3.3 전문 문서 생성

- **Excel 스프레드시트**: 수식이 작동하는 완성된 엑셀 파일
- **PowerPoint 프레젠테이션**: 포맷이 갖춰진 PPT 파일
- **서식 문서**: 구조화된 비즈니스 문서

### 3.4 외부 서비스 연동 (커넥터)

- Asana, Notion 등 외부 서비스와 연동 가능
- **Skills** 시스템을 통해 문서/프레젠테이션 생성 역량 강화

### 3.5 다중 태스크 큐잉

- 여러 작업을 동시에 요청하고 병렬 처리 가능
- Anthropic의 표현에 따르면, "왔다 갔다 하는 대화가 아닌, **동료에게 메모를 남기는 것** 같은 워크플로우"

## 4. 내부 아키텍처: 서브에이전트 시스템

Cowork의 핵심은 **서브에이전트 아키텍처**에 있다. 이 시스템이 Cowork를 단순 챗봇과 구별하는 가장 중요한 기술적 차별점이다.

### 4.1 태스크 분해 및 계획 (Task Decomposition)

```
사용자 요청
    │
    ▼
┌──────────────────────┐
│  1. 목표 분석 (Parse) │  ← 의도 파악, 범위 결정
├──────────────────────┤
│  2. 계획 수립 (Plan)  │  ← DAG(방향 비순환 그래프) 형태로 서브태스크 분해
├──────────────────────┤
│  3. 에이전트 생성     │  ← 독립 태스크별 서브에이전트 스폰(Spawn)
│     (Spawn)          │
├──────────────────────┤
│  4. 병렬 실행         │  ← 각 서브에이전트가 독립적으로 동시 실행
│     (Execute)        │
├──────────────────────┤
│  5. 결과 집계         │  ← 모든 서브에이전트 결과를 메인 컨텍스트로 통합
│     (Aggregate)      │
├──────────────────────┤
│  6. 최종 전달         │  ← 완성된 산출물을 사용자에게 제공
│     (Deliver)        │
└──────────────────────┘
```

### 4.2 의존성 그래프 (DAG) 기반 태스크 관리

기존의 단순 리스트(To-do)가 아닌, **방향 비순환 그래프(DAG)** 형태로 태스크 간 의존성을 관리한다.

예시:
```
태스크1 (API 구축) ──┐
                     ├──→ 태스크3 (테스트 실행)
태스크2 (인증 설정) ──┘
```

- 태스크3은 태스크1과 태스크2가 완료되어야만 시작
- LLM이 아직 작성하지 않은 코드를 테스트하려는 "환각적 완료(hallucinated completion)" 오류를 방지

### 4.3 서브에이전트의 특성

각 서브에이전트는 다음의 독립적인 구성요소를 가진다:

| 구성요소 | 설명 |
|----------|------|
| 컨텍스트 윈도우 | 독자적인 컨텍스트 윈도우에서 작동 |
| 시스템 프롬프트 | 태스크에 특화된 커스텀 시스템 프롬프트 |
| 도구 접근 | 필요한 도구에만 선택적으로 접근 가능 |
| 권한 | 독립적인 실행 권한 |
| 영구 메모리 | 대화를 넘어 유지되는 메모리 디렉토리 |

### 4.4 컨텍스트 관리

- 서브에이전트 완료 시 결과가 메인 대화로 복귀
- 다수의 서브에이전트가 상세한 결과를 반환하면 컨텍스트 소비가 증가
- 지속적인 병렬 처리가 필요하거나 컨텍스트 윈도우 한계를 초과할 경우, **에이전트 팀(Agent Teams)** 체계로 전환하여 각 워커에게 독립적인 컨텍스트 부여

### 4.5 상태 관리: UNIX 철학

Anthropic은 상태 관리에 "UNIX 철학" 접근법을 채택했다:

- 프로젝트 상태를 독점 클라우드 DB에 저장하는 대신, **로컬 파일시스템** (`~/.claude/tasks`)에 직접 기록
- 컨텍스트를 비워도(`/clear`, `/compact`) 프로젝트 로드맵이 디스크에 저장되어 있으므로 안전
- "공격적 컨텍스트 관리(aggressive context management)"가 가능

## 5. 작동 원리

### 5.1 설정 과정

1. **Claude Desktop 앱** 설치 (현재 macOS만 지원)
2. Claude Max 구독 활성화 ($100 또는 $200/월)
3. Cowork에 접근할 **폴더 지정** (읽기/쓰기/생성 권한 부여)
4. 채팅 인터페이스를 통해 작업 지시

### 5.2 실행 흐름

```
[사용자] "이 폴더의 데이터를 분석하고 보고서를 만들어줘"
    │
    ▼
[Claude] 폴더 내 파일 스캔 및 구조 파악
    │
    ▼
[Claude] 작업 계획 수립 → 사용자에게 계획 공유
    │
    ▼
[Claude] 서브에이전트 생성:
    ├── 에이전트 A: CSV 데이터 분석
    ├── 에이전트 B: 차트/그래프 생성
    └── 에이전트 C: 보고서 템플릿 작성
    │
    ▼
[Claude] 결과 통합 → 최종 보고서(Excel/PPT/Word) 생성
    │
    ▼
[사용자] 지정 폴더에서 완성된 파일 확인
```

### 5.3 실행 중 사용자 개입

- **투명성**: Claude가 자신의 추론 과정과 접근 방식을 실시간으로 공개
- **조정(Steering)**: 작업 중간에 방향 수정이나 추가 지시 가능
- **장애 대응**: 난관에 봉착하면 Claude가 사용자에게 명확한 질문을 던짐

## 7. 윈도우 지원 현황

### 현재 상태 (2026년 2월 기준)

| 항목 | 상태 |
|------|------|
| macOS | **정식 지원** (Research Preview) |
| Windows | **미지원** (개발 중) |
| Linux | 미정 |

### 윈도우 출시 일정

- Anthropic이 **Windows 버전 활발히 개발 중**임을 공식 확인
- 목표 출시 시기: **2026년 중반 (Q2~Q3)**
- 업계 전문가들은 **2026년 Q2** 출시를 예상하나 공식 날짜는 미정
- [claude.ai](https://claude.ai)에서 **대기자 명단(Waitlist)** 등록 가능

### 윈도우 사용자를 위한 현재 대안

#### 1. Claude Code (CLI) - 윈도우 네이티브 지원

2025년에 이미 윈도우 네이티브 버전이 출시되었다. 최신 버전은 v2.1.34 (2026년 2월 기준).

```powershell
# PowerShell에서 직접 설치 (WSL 불필요)
npm install -g @anthropic-ai/claude-code
```

- 과거에는 WSL(Windows Subsystem for Linux)이 필요했으나, 현재는 **PowerShell에서 직접 실행** 가능
- Cowork의 기반 기술인 에이전트 아키텍처를 CLI 환경에서 동일하게 활용 가능

#### 2. Claude 웹 인터페이스

- [claude.ai](https://claude.ai)에서 웹 브라우저를 통해 접속
- Cowork의 로컬 파일 접근 기능은 없지만 대화형 AI 기능은 동일

#### 3. Claude Code + 서브에이전트 활용

윈도우에서 Claude Code를 사용하면서 서브에이전트 기능을 직접 활용할 수 있다:

```bash
# 서브에이전트를 포함한 Claude Code 설정 예시
claude --config subagents.yaml
```

## 8. Claude Code와의 비교

| 항목 | Claude Code | Claude Cowork |
|------|-------------|---------------|
| 대상 사용자 | 소프트웨어 개발자 | 모든 지식 노동자 |
| 인터페이스 | 터미널 (CLI) | GUI (데스크톱 앱) |
| 주요 작업 | 코딩, 디버깅, 리팩토링 | 문서 정리, 데이터 분석, 프레젠테이션 |

| 기반 기술 | 동일한 에이전트 아키텍처 | 동일한 에이전트 아키텍처 |
| 서브에이전트 | 지원 | 지원 |
| 요금 | Pro 이상 ($20~) | Pro 이상 ($20~) |

핵심 차이: Cowork는 **Claude Code의 에이전트 아키텍처를 비개발자도 사용할 수 있도록 GUI화**한 것이다.

## 9. 실제 활용 사례

### 9.1 문서 정리 및 변환
- 흩어진 메모와 노트를 구조화된 문서로 통합
- 다양한 형식의 파일을 원하는 포맷으로 변환

### 9.2 데이터 분석 및 보고서 생성
- CSV/Excel 데이터를 분석하여 인사이트 도출
- 차트와 그래프가 포함된 보고서 자동 생성

### 9.3 프레젠테이션 제작
- 원천 자료에서 발표용 PPT를 자동 생성
- 슬라이드 디자인과 내용 구성을 동시에 처리

### 9.4 파일 관리 자동화
- 대량의 파일을 규칙에 따라 분류 및 정리
- 파일명 일괄 변경, 폴더 구조 재편성

### 9.5 리서치 및 요약
- 다수의 문서를 교차 분석하여 핵심 내용 요약
- 경쟁사 분석, 시장 조사 보고서 작성

## 10. 보안 및 안전장치

### 폴더 권한 모델
- 사용자가 **명시적으로 지정한 폴더**에만 접근 가능
- 읽기, 쓰기, 생성 권한을 개별적으로 제어

### 가상화 격리
- Apple의 **Virtualization Framework** 위에서 실행
- 호스트 운영체제로부터 격리된 가상 머신 환경 제공

### 삭제 보호
- 파일 영구 삭제 시 **반드시 사용자의 명시적 허가** 필요
- 실수로 인한 데이터 손실 방지

### 투명성
- 모든 작업 과정을 실시간으로 사용자에게 공개
- 어떤 파일에 접근하고, 어떤 변경을 가하는지 확인 가능

## 11. 제한사항 및 주의점

### 현재 제한사항
1. **macOS 전용** - 윈도우/리눅스 미지원 (2026년 2월 기준)
2. **리소스 소비** - 복잡한 작업은 일반 대화 대비 50~100배 쿼터 소비
3. **Research Preview** - 아직 정식 출시 단계가 아닌 연구 프리뷰
4. **인터넷 연결 필수** - 클라우드 기반 AI 모델 호출 필요
5. **컨텍스트 윈도우 한계** - 극히 대량의 파일 처리 시 한계 존재

### 주의사항
- 민감한 개인정보나 기밀 파일은 접근 폴더에서 제외할 것
- 중요 파일 작업 전에는 백업을 권장
- 대용량 작업 시 요금제 쿼터 소진에 주의
