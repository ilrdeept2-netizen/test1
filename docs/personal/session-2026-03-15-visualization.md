# 세션 기록: 2026-03-15 — Claude 시각화 위젯 분석

## 논의 주제

Claude의 새 시각화 기능 (Show Me 위젯) vs 기존 Artifacts 비교 분석

## 새 시각화 기능 요약

- 프롬프트만 입력하면 실시간 인터랙티브 시각화 자료 자동 생성
- 식단 업로드 → 탄단지 비율·칼로리 차트 (마우스 호버 시 수치 표시)
- 방 크기·가구 사이즈 입력 → 2D 평면도 생성 + 배치 최적화 제안
- 3D 모델링 지원 (드래그 회전, 스크롤 확대·축소)
- 오래된 데이터 자동 삭제 가능 → 다운로드 필수

## 핵심 분석: Artifacts vs Show Me 위젯

| 항목 | 기존 Artifacts | 새 위젯 (Show Me) |
|------|---------------|-------------------|
| 렌더링 위치 | 별도 사이드 패널 | 대화 인라인 |
| 생성 트리거 | 사용자 명시적 요청 필요 | Claude가 자동 판단하여 생성 |
| 인터랙션 | 패널 전환 필요 | 채팅 내에서 바로 hover/drag/scroll |
| 컨텍스트 | 대화 ↔ 시각물 분리 | 대화 흐름 속에 통합 |
| 수정 루프 | 패널 왔다갔다 | 인라인에서 자연스러운 후속 수정 |
| 성격 | "도구를 꺼내서 작업물 제작" | "대화 자체가 시각화 포함" |

## 결론

- 기술적 기반(HTML/JS 렌더링, 인터랙티브 차트)은 Artifacts와 공유
- 본질적 차이는 **UX 패러다임 전환**: 시각화를 "특별한 기능"이 아닌 "기본 응답 형태"로 만듦
- 대화와 시각물 사이의 마찰(friction) 제거가 핵심 가치
