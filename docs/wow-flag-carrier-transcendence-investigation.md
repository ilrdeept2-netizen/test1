# WoW 전장 깃발 소지 시 해탈(Transcendence) 사용 불가 조사 보고서

## 질문 요약
- PvP 블리츠/일반 전장에서 운무 수도사가 깃발을 들고 해탈(Transcendence: Transfer) 텔레포트로 깃수(깃발 수비/운반)를 하던 것이 가능했음
- 한밤(Midnight) 확장팩에서 난투(Brawl) 전장을 플레이해보니 깃발을 든 상태에서 해탈이 발동되지 않는 현상 확인

## 조사 결과

### 1. 공식 패치노트 확인 결과
- **한밤(Midnight) 12.0 콘텐츠 업데이트 패치노트**, **한밤 사전 패치(12.0.0/12.0.1) 패치노트**, **최근 핫픽스(2026년 3월 19일까지)** 등을 확인한 결과, **깃발 소지 시 해탈(Transcendence: Transfer) 사용을 명시적으로 제한하는 패치노트 항목은 발견되지 않았습니다.**
- 한밤 12.0에서 수도사 관련 대규모 능력 정리가 있었으며, 일부 능력이 삭제되었으나 해탈 자체가 삭제된 것은 아닙니다.
- **2026년 3월 핫픽스에서 수도사 관련 변경**: "Dance of the Wind와 Transcendence가 쿨다운 매니저에 추가됨" — 이는 UI/쿨다운 추적 개선이며, 능력 제한과는 무관합니다.

### 2. 기존에 알려진 깃발 소지 시 능력 제한 (역사적 맥락)

#### 깃발을 떨어뜨리는 능력 (Flag Drop)
- **성기사 신성한 보호막(Divine Shield/버블)**: 깃발을 즉시 떨어뜨림
- **마법사 얼음 방패(Ice Block)**: 깃발을 즉시 떨어뜨림
- **도적 소멸(Vanish)**: 깃발을 즉시 떨어뜨림 (은신 해제 시 다시 습득 가능)
- **탈것 탑승(Mounting)**: 깃발을 떨어뜨림
- **완전 면역 효과를 부여하는 모든 능력**: 깃발 떨어뜨림

#### 깃발 소지 시 사용 불가 능력
- **수도사 구르기(Roll)**: 사용 불가
- **수도사 비룡각(Flying Serpent Kick)**: 사용 불가
- **흑마법사 악마의 관문(Demonic Gateway)**: 사용 불가
- **사제 신앙의 도약(Leap of Faith)**: 깃발 운반자를 끌어올 수 없음 (쌍둥이 봉우리 묘지 끌어올리기 패치됨)

#### 깃발 소지 중에도 사용 가능한 이동기 (논란 대상)
- **수도사 해탈(Transcendence: Transfer)**: 역사적으로 깃발 소지 중 사용 가능
- **수도사 기 어뢰(Chi Torpedo)**: 사용 가능
- **전사 영웅의 도약(Heroic Leap)**: 사용 가능
- **악마사냥꾼 이동기**: 일부 사용 가능
- **기원사 이동기**: 사용 가능

### 3. 일반 전장/블리츠에서의 해탈 사용 현황 (2026년 3월 기준)

#### Icy Veins 가이드 확인 (Midnight Season 1, 2026년 3월 최신)
- **운무(Mistweaver) 블리츠 가이드**: "Transcendence를 사용해 기둥 뒤로 텔레포트할 수 있다"고 명시. 깃발 운반 시에도 여전히 전략적 도구로 언급됨.
- **풍운(Windwalker) 블리츠 가이드**: "공격 전에 Transcendence를 설치해두면 피해를 많이 받을 때 Transfer로 빠져나올 수 있다"고 안내.
- **결론**: Icy Veins의 최신 가이드에서 해탈은 **일반 전장/블리츠에서 깃발 소지 중에도 여전히 사용 가능한 것으로 기술**되어 있음.

#### 커뮤니티 반응 (2025~2026)
- **2025년 1월**: "수도사가 깃발을 들고 Transcendence를 사용할 수 있는 것이 어떻게 허용되는 것인가" (블리자드 포럼)
- **2025년 5월**: 깃발 운반자의 이동기를 비활성화해야 한다는 요청 (수도사, 기원사, 무법 도적 등 언급)
- 운무 수도사는 블리츠에서 "완전히 사기급(absolutely busted)"으로 강력한 깃발 운반자라는 평가가 지속됨
- **블리자드의 공식 응답이나 변경 발표는 확인되지 않음**

### 4. 이번주 난투: 전쟁노래 쟁탈전(Warsong Scramble) 특수 규칙

이번주 난투가 **전쟁노래 쟁탈전(Warsong Scramble)**인 것이 확인되었습니다. 이 난투는 일반 전쟁노래 협곡과 상당히 다른 규칙을 가집니다:

- 각 진영에 **깃발 3개**씩 배치 (일반: 1개)
- **10캡** 먼저 달성 시 승리 (일반: 3캡)
- 아군 깃발 회수 없이도 적 깃발 반납 가능
- 제한시간 15분
- 맵에 특수 버프 큐브 배치 (아케인 감옥, 분해광선, 잡아끄는 쇠사슬, 초강력 발차기)
- **깃발 운반자 디버프(Focused Assault/Brutal Assault)가 비정상적으로 스택**된다는 버그 리포트가 과거에 존재

**난투 고유의 깃발 운반자 능력 제한 규칙이 별도로 존재하는지에 대한 공식 문서는 확인 불가했으나**, 난투마다 고유한 규칙 세트가 적용되므로 일반 전장과 다른 제한이 있을 가능성이 있습니다.

### 5. 원인 분석

해탈이 난투에서 안 나가는 현상에 대해 다음과 같은 가능성이 있습니다:

#### 가능성 A: 전쟁노래 쟁탈전(Warsong Scramble) 난투 고유 규칙 ⭐ 유력
- 전쟁노래 쟁탈전은 동시에 3명이 깃발을 운반하는 특수 난투임
- 깃발 3개+빠른 캡 특성상, 해탈 같은 강력한 텔레포트 이동기가 너무 유리하므로 **난투 한정으로 추가 이동기 제한**이 걸려 있을 수 있음
- 일반 전장/블리츠에서는 가이드 기준 여전히 사용 가능

#### 가능성 B: 한밤 12.0 미기록 변경(Undocumented Change)
- 한밤 패치에서 수도사 능력이 대폭 정리되면서, 깃발 소지 시 해탈 사용 제한이 문서화되지 않은 변경으로 적용되었을 수 있음
- 단, Icy Veins 최신 가이드에서 해탈을 전장 전략으로 여전히 소개하고 있어 **전면 제한 가능성은 낮음**

#### 가능성 C: 패치 5.5.0(2025.07) 해탈 범위 제한의 영향
- Warcraft Wiki에 따르면, 패치 5.5.0 이후 Transcendence: Transfer는 **활성화된 해탈 영혼이 있고 범위 내에 있을 때만 사용 가능**하도록 변경됨
- 전장에서 깃발을 들고 멀리 이동하면 해탈 영혼이 범위 밖이 되어 사용이 안 될 수 있음
- **깃발 미소지 시에도 같은 거리에서 해탈이 안 되는지 테스트 필요**

#### 가능성 D: 버그
- 한밤 패치 이후 다양한 PvP 버그가 보고되고 있으며, 전쟁노래 쟁탈전의 디버프 스택 버그 등 전례도 있음
- 의도치 않은 상호작용일 수 있음

### 6. 결론

| 모드 | 해탈+깃발 사용 가능 여부 | 근거 |
|------|-------------------------|------|
| **일반 전장** (전노/쌍봉) | ✅ 사용 가능 (추정) | Icy Veins 최신 가이드에서 전략으로 소개, 커뮤니티 불만 지속 |
| **블리츠 전장** | ✅ 사용 가능 (추정) | Icy Veins Midnight S1 가이드에서 해탈 깃발 운반 전략 소개 |
| **난투 (전쟁노래 쟁탈전)** | ❌ 사용 불가 (제보 기준) | 난투 고유 규칙 또는 범위 제한/버그 가능성 |

**가장 유력한 결론**: 일반 전장/블리츠에서는 해탈+깃발이 여전히 가능하나, **전쟁노래 쟁탈전 난투에서만 추가적인 이동기 제한이 적용**되거나, 난투 특성상 해탈 범위를 벗어나기 쉬운 환경이 원인일 수 있습니다.

**추가 확인 권장:**
1. 일반 전쟁노래 협곡에서 깃발+해탈 테스트 → 작동하면 난투 고유 규칙 확정
2. 난투에서 깃발 없이 해탈 테스트 → 작동하면 깃발 관련 제한 확정
3. 난투에서 해탈 영혼을 가까이 설치 후 깃발+해탈 테스트 → 작동하면 범위 문제
4. 블리자드 공식 버그 포럼에 제보
