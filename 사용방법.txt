====================================================
특허 문서 변환기 - 간단 사용 설명서
Patent Document Converter - Quick Start Guide
====================================================

📥 1단계: 파일 다운로드
----------------------------------------------------
GitHub에서 ZIP 파일로 다운로드:
https://github.com/ilrdeept2-netizen/test1

→ 초록색 "Code" 버튼 클릭
→ "Download ZIP" 클릭
→ 원하는 폴더에 압축 풀기


💻 2단계: 실행하기
----------------------------------------------------

▶️ Windows 사용자:
   "특허변환기_실행.bat" 파일을 더블클릭!

▶️ Mac/Linux 사용자:
   "start_converter.sh" 파일을 더블클릭!


🌐 3단계: 브라우저에서 사용
----------------------------------------------------
자동으로 브라우저가 열립니다!

안 열리면 브라우저 주소창에 입력:
http://localhost:5000


📄 4단계: 파일 변환
----------------------------------------------------
1. 웹페이지에서 Word 파일을 드래그 앤 드롭
2. 자동으로 HLT 파일 다운로드!
3. K-Editor에서 열어서 사용하세요


📝 문서 작성 팁
----------------------------------------------------
변환이 잘 되려면 Word 문서에 이런 형식으로 작성하세요:

【발명의 명칭】
여기에 발명 제목

【기술분야】
여기에 기술 분야 설명

【청구범위】
청구항 1: ...
청구항 2: ...


❓ 문제 해결
----------------------------------------------------

Q: "Python이 설치되어 있지 않습니다" 오류가 나요
A: Python을 먼저 설치하세요
   https://www.python.org/downloads/
   ※ 설치할 때 "Add Python to PATH" 체크!

Q: 브라우저가 안 열려요
A: 수동으로 브라우저를 열고 주소창에 입력하세요
   http://localhost:5000

Q: 변환이 안 돼요
A: Word 문서에 【】 괄호를 사용했는지 확인하세요
   일반 [] 괄호가 아니라 특수문자 【】 입니다
