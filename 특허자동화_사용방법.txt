================================================================================
                    특허 업무 자동화 시스템 사용 방법
                    Patent Application Automation System
================================================================================

【개요】
이 시스템은 특허 명세서 작성, 도면 관리, 청구항 작성, OA 대응 등
특허 업무 전반을 AI를 활용하여 자동화하는 웹 애플리케이션입니다.

================================================================================
【설치 및 실행】
================================================================================

1. 필수 요구사항
   - Python 3.8 이상
   - AI API 키 (OpenAI, Anthropic, Google 중 하나 이상)

2. 설치
   pip install flask openai anthropic google-generativeai

3. API 키 설정 (환경 변수)

   Windows:
   set OPENAI_API_KEY=sk-...
   set ANTHROPIC_API_KEY=sk-ant-...
   set GOOGLE_API_KEY=...

   Mac/Linux:
   export OPENAI_API_KEY='sk-...'
   export ANTHROPIC_API_KEY='sk-ant-...'
   export GOOGLE_API_KEY='...'

4. 실행
   python start_patent_automation.py

   브라우저가 자동으로 열리며 http://localhost:5001 로 접속됩니다.

【주요 기능】
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 명세서 작성                                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 기술분야, 배경기술, 해결과제, 발명의 효과, 도면 설명, 상세한 설명 작성     │
│ • 발명자 초안 검토 및 보완                                                   │
│ • 번역 친화적 간결체 자동 적용                                               │
│   - 접속사 삭제 (그리고, 또한, 나아가 등)                                    │
│   - 지시어 최소화 (상기, 본, 이러한 등)                                      │
│   - 단문 위주 서술                                                           │
│   - 능동태 지향                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. 도면 관리                                                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 도면 계획 수립 (5-6장 구성)                                                │
│ • HTML 기반 특허 도면 생성                                                   │
│ • 부호체계 자동 생성 및 관리                                                 │
│   - 구성요소에 부호 자동 부여                                                │
│   - '/' 나 '및' 제외                                                         │
│   - 단계는 SXX 형식 부여                                                     │
│   - 영문 제외, 한글 명칭 사용                                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. 청구항 작성                                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 독립항 1항 작성 (넓은 권리범위)                                            │
│ • 종속항 자동 작성 (특징별 1개씩)                                            │
│ • 청구항 검토 및 누락 특징 확인                                              │
│ • 명세서와 청구항 정합성 확인                                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. OA 대응                                                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 거절이유 분석 및 정당성 검토                                               │
│ • 청구항 보정안 작성                                                         │
│ • 의견서 작성 (보정 근거, 진보성 주장)                                       │
│ • 원청구항/보정청구항 비교 (변경점 강조)                                     │
│ • 종속항 보정 (번호 유지)                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. 자동 워크플로우                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ • 전체 명세서 자동 작성                                                      │
│   발명 정보 입력 → 도면 계획 → 부호체계 → 명세서 → 청구항                    │
│ • OA 대응 자동화                                                             │
│   거절이유 분석 → 청구항 보정 → 의견서 작성                                  │
└─────────────────────────────────────────────────────────────────────────────┘

【사용 팁】
================================================================================

1. 발명 내용 입력 시
   - 기술적 특징을 구체적으로 기술
   - 구성요소, 동작 원리, 효과를 포함
   - 발명자가 작성한 초안이 있으면 함께 입력

2. 도면 작성 시
   - 모든 구성요소에 부호 부여
   - 부호숫자로 설명하는 것이 원칙

3. OA 대응 시
   - 인용문헌 내용을 정확히 입력
   - 본 발명과의 차이점을 구체적으로 파악

4. AI 선택
   - OpenAI GPT-4: 범용적 성능 우수
   - Anthropic Claude: 긴 문서 처리에 강점
   - Google Gemini: 빠른 응답 속도

【프롬프트 카테고리】
================================================================================

• 명세서 항목 작성 (specification)
• 서술 방식 (writing_style)
• 도면 관리 (drawing)
• OA 대응 (oa_response)
• 발명자 초안 검토 (inventor_draft)
• 상세한 설명 작성 (detailed_description)
• 본문 보완 (supplement)
• 청구항 작성 (claims)
• 분석 및 정리 (analysis)
