      → 앱처럼 사용 가능!

===============================================================================
                          사용 방법
===============================================================================

[기본 실행 - 오늘 뉴스 보기]

   python ai_news_digest.py

[옵션]

   -d, --days <숫자>    수집할 기간 (일 단위, 기본값: 1)
   -s, --save           결과를 파일로 저장
   -o, --output <경로>  출력 디렉토리 지정
   -q, --quiet          조용한 모드 (파일 저장만)

[예시]

   # 최근 3일 뉴스 보기
   python ai_news_digest.py -d 3

   # 파일로 저장
   python ai_news_digest.py --save

   # 특정 폴더에 저장
   python ai_news_digest.py -s -o ./news

   # 조용히 파일만 저장
   python ai_news_digest.py -s -q

===============================================================================
                      자동 실행 설정
===============================================================================

[방법 1: GitHub Actions (권장)]

GitHub에 푸시하면 매일 아침 8시(한국 시간)에 자동으로 실행됩니다.
- 결과는 GitHub Issues에 자동으로 생성됩니다.
- Actions 탭에서 수동으로 실행할 수도 있습니다.

[방법 2: Windows 작업 스케줄러]

1. 작업 스케줄러 열기
2. "기본 작업 만들기" 선택
3. 트리거: 매일 오전 8:00
4. 동작: 프로그램 시작
   - 프로그램: python
   - 인수: ai_news_digest.py -s -o C:\news
   - 시작 위치: (이 프로젝트 폴더 경로)

[방법 3: Linux/Mac Cron]

   # crontab 편집
   crontab -e

   # 매일 8시에 실행 추가
   0 8 * * * cd /path/to/project && python ai_news_digest.py -s -o /path/to/output
