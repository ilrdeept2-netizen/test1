============================================================
        🔍 선행특허조사 앱 사용 설명서
============================================================

【 개요 】
---------------------------------------------------------
선행특허조사 앱은 특허 관련 문서(발명설명서, 기술문서 등)를
업로드하면 자동으로 유사한 선행특허를 검색해주는 앱입니다.

【 지원 파일 형식 】
---------------------------------------------------------
• Word 문서: .docx, .doc
• 한글(HWP): .hwp
• PDF: .pdf
• PowerPoint: .pptx, .ppt
• Excel: .xlsx, .xls
• 텍스트: .txt

【 실행 방법 】
---------------------------------------------------------

■ 방법 1: 웹 UI로 실행 (권장)

  Windows:
    1. "선행특허조사_실행.bat" 파일을 더블클릭
    2. 웹 브라우저에서 http://localhost:8501 접속
    3. 문서 업로드 후 '분석 시작' 클릭

  Linux/Mac:
    1. 터미널에서 ./start_patent_search.sh 실행
    2. 웹 브라우저에서 http://localhost:8501 접속
    3. 문서 업로드 후 '분석 시작' 클릭

■ 방법 2: 명령줄로 실행

    python patent_search_app.py <파일경로>

  예시:
    python patent_search_app.py 발명설명서.docx
    python patent_search_app.py 기술문서.pdf

【 주요 기능 】
---------------------------------------------------------

1. 텍스트 추출
   - 다양한 파일 형식에서 자동으로 텍스트 추출
   - 한글/영어 문서 모두 지원

2. 키워드 분석
   - 문서에서 핵심 키워드 자동 추출
   - 불용어 자동 제거
   - 기술 용어/약어 별도 추출

3. 특허 검색
   - KIPRIS(한국특허정보원) API를 통한 특허 검색
   - 키워드 기반 유사 특허 검색
   - 데모 모드 지원 (API 키 없이도 테스트 가능)

4. 유사도 분석
   - 문서와 특허 간 유사도 자동 계산
   - 유사도 순으로 결과 정렬

5. 결과 다운로드
   - 텍스트 보고서 (.txt)
   - JSON 데이터 (.json)
   - CSV 데이터 (.csv)

【 KIPRIS API 키 설정 (선택사항) 】
---------------------------------------------------------
실제 특허 검색을 위해서는 KIPRIS API 키가 필요합니다.

1. http://plus.kipris.or.kr 접속
2. 회원가입 및 로그인
3. 'Open API 신청' 메뉴에서 API 키 발급
4. 환경 변수 설정:

   Windows:
     set KIPRIS_API_KEY=발급받은키

   Linux/Mac:
     export KIPRIS_API_KEY='발급받은키'

※ API 키가 없어도 데모 모드로 앱을 테스트할 수 있습니다.

【 문제 해결 】
---------------------------------------------------------

Q: "streamlit 모듈을 찾을 수 없습니다" 오류가 발생해요
A: pip install streamlit 명령으로 설치하세요

Q: HWP 파일이 제대로 읽히지 않아요
A: HWP 파일은 기본적인 텍스트만 추출됩니다.
   더 정확한 추출을 위해서는 pyhwpx 라이브러리가 필요합니다.
   (Windows에서만 지원)

Q: PDF에서 텍스트가 추출되지 않아요
A: 스캔된 PDF(이미지 PDF)는 텍스트 추출이 어렵습니다.
   OCR 처리된 PDF나 디지털 PDF를 사용해주세요.

Q: 특허 검색 결과가 나오지 않아요
A: KIPRIS API 연결에 문제가 있을 수 있습니다.
   네트워크 연결을 확인하거나, 데모 모드로 테스트해보세요.
